# Luxesonics Designs

Live production planner for audio, lighting and video: input lists, patch sheets, stage plots, console choice, gear lists, call times, PA, personal monitors, racks, scene export and scene transfer.

**Open the app:** https://mixedbymz.github.io/luxsonics-Designs/

## Install on a phone or tablet
- **iPhone / iPad:** open the link in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open it in Chrome, tap the menu, then **Install app**.

It opens full-screen and works offline after the first visit. Shows and gear are saved on each device.

## Updating the site
Replace `index.html` with the new build and change `VERSION` in `sw.js`, so installed copies pick up the update.
